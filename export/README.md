# Печатные версии

`python build.py --export latex` и `--export docx` проверяют возможность получить общий текст
из тех же исходников. Выход находится в `.build/exports/` и не хранится в Git.

В дальнейшем здесь будут настройки нормативного оформления, шаблон LaTeX/Word,
стиль библиографии и правила выбора текста для диссертации и автореферата.
Текущий экспорт не является готовым документом для защиты.
