Глава 2. Метод и эксперимент

Вторая глава демонстрирует переходы между главами, код и оформление результатов.

2.1. Описание метода

Используем постановку из § 1.2. Сначала объясните идею метода словами, затем запишите алгоритм и уточните область его применимости.

def mean(values):
    if not values:
        raise ValueError("Нужны непустые данные")
    return sum(values) / len(values)

2.1.1. Ограничения

  • Укажите, какие данные метод принимает.
  • Объясните, когда предположения нарушаются.
  • Отделите теоретическое утверждение от результата отдельного эксперимента.
