# Шаблон оформления глав

Переносимая версия оформления глав курса: Markdown → HTML. В архив входят
два коротких примера, исходный стиль, сборщик и уже собранный каталог `docs/`.
Материалы самих лекций, личные пути и служебные файлы проекта не включены.

## Посмотреть сразу

Откройте `docs/index.html` двойным щелчком. Python для просмотра не нужен.
**Для отображения формул нужен интернет:** MathJax 3.2.2 загружается с CDN.
Остальные элементы и пример рисунка локальные. Для полностью автономной версии
нужно скачать MathJax вместе с его ресурсами и заменить адрес в `build.py`.

## Пересобрать после изменения текста

Нужен Python 3.10 или новее. Откройте терминал в распакованной папке.

macOS / Linux:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python build.py
```

Windows (PowerShell; активация окружения не обязательна):

```powershell
py -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe build.py
```

После сборки откройте `docs/index.html` и обновите страницу. Сборщик работает
и при запуске по абсолютному пути из другой папки. Он перезаписывает HTML
в `docs/`: редактируйте Markdown, а не результат сборки.

## Что менять

- `book.json`: название работы, автор/организация и список глав.
- `chapters/chapter01.md`, `chapter02.md`: текст глав.
- `assets/`: собственные рисунки PNG или JPEG.
- `style.css`: палитра, ширина текста, шрифты и оформление печати.
- `glossary_rus.json`: необязательные подсказки для обычных ссылок; можно оставить `{}`.

Чтобы добавить главу, создайте `chapters/chapter03.md` и добавьте в массив
`chapters` в `book.json` объект:

```json
{
  "output": "chapter03.html",
  "source": "chapters/chapter03.md",
  "title": "Глава 3. Результаты"
}
```

Сохраняйте имена выходных страниц `chapterNN.html`: номер используется
для автоматических ссылок между разделами. Не повторяйте номера разделов.

## Правила разметки

- `#` — название главы, `##` — раздел, `###` — подраздел.
- Номера пишутся вручную: `## 1.2. Постановка задачи`.
- Оглавление слева строится автоматически по `##` и `###`.
- `§ 1.2` и `§ 2.1` автоматически превращаются в ссылки.
  Сборщик сообщает об отсутствующих целях и завершает работу с ошибкой.
- Для ссылки на раздел чужого источника используйте `§&nbsp;5.3`, чтобы
  не создавать ссылку на собственную главу.
- Формулы: `$x_i$` внутри строки и `$$ ... $$` отдельным блоком.
- Рисунок: `![Описание](assets/example.png)`. Путь задаётся **от корня шаблона**,
  а не от папки `chapters/`. Используйте простые имена без пробелов и скобок.
- Подпись отдельным абзацем: `*Рис. 1.1. Содержательная подпись.*`.
- Сборщик уменьшает растровые рисунки шире 1600 px для браузера и складывает
  копии в `docs/img/`. Исходники из `assets/` остаются без изменений.
- Таблицы — стандартная Markdown-разметка; код — между тройными обратными кавычками.
- Раздел `## Обозначения` с таблицей «Обозначение | Значение» добавляет подсказки
  к первым употреблениям соответствующих формул в разделах.
- Для подсказки к внешней ссылке добавьте в `glossary_rus.json` запись вида
  `"https://example.org": {"tip": "Краткое пояснение"}`.

Ссылки на рисунки, нумерация формул и библиография задаются вручную.
Markdown допускает HTML: собирайте только свои или доверенные исходники.

## Передать или опубликовать

Для чтения достаточно передать папку `docs/` целиком, включая `img/`.
Для дальнейшего редактирования передайте весь этот архив.

## Диссертация и PDF

Это **шаблон оформления электронного текста**, а не готовый нормативный шаблон
диссертации по ГОСТ или требованиям конкретного вуза. Титульный лист,
библиографический стиль, поля, интервалы, колонтитулы и сквозную нумерацию
страниц следует согласовать с требованиями организации.

Предварительный PDF отдельной главы: откройте её в браузере, дождитесь формул,
нажмите «Печать → Сохранить как PDF», выберите A4 и отключите браузерные
колонтитулы. Оглавление сбоку скрывается при печати. Это не сборка единого
печатного тома: такой функции и автоматической диссертационной вёрстки здесь нет.
